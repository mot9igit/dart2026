ПСТМ — завод по производству металлоконструкций и профнастила. К нам пришли с типовой, но непростой задачей: старый сайт не продавал, каталог обновлялся вручную раз в полгода, а заявки терялись. Рассказываю, как мы подошли к проекту — от брифа до поддержки.

1. Задача и исходные данные

На старте у клиента был сайт-витрина на устаревшей CMS: без адаптива, с неработающим калькулятором и каталогом, который обновлял один инженер «по вечерам». Конкуренты уже обгоняли его в поиске, а менеджеры обрабатывали заявки вручную из почты и мессенджеров.

Сформулировали три ключевые цели:

  • Продающий каталог — автоматическая выгрузка товаров и цен из 1С, удобные фильтры и карточки.
  • Заявки без потерь — формы обратной связи с отправкой в CRM и Telegram, уведомления менеджерам.
  • Рост в поиске — SEO-оптимизация структуры и текстов с первого дня разработки.
Ключевая сложность

Каталог насчитывал более 2 000 позиций с разными ценовыми политиками для опта и розницы — вручную это не вести. Интеграция с 1С стала обязательным условием.

2. Структура и прототип

Начали с прототипирования: собрали структуру сайта, разложили по важности сценарии пользователей («застройщик», «оптовый покупатель», «частный клиент») и согласовали путь заявки. Всё зафиксировали в документе, чтобы команда и клиент говорили на одном языке.

  • Главная — о компании, преимуществах и ключевых продуктах.
  • Каталог — до 3 уровней вложенности, фильтры, сравнение, избранное.
  • Калькулятор — примерный расчёт стоимости конструкции по параметрам.
  • Проекты и отзывы — кейсы для убеждения на этапе выбора.
  • Блог и новости — база для SEO-продвижения.

3. Стек и реализация

В качестве платформы выбрали MODX Revolution: гибкая архитектура под сложный каталог, удобная админ-панель для заказчика и возможность точечной оптимизации под производительность.

Технологии

MODX Revolution · PHP · MySQL · JQuery + собственные компоненты · REST API для 1С · адаптивная вёрстка

Пример логики интеграции каталога из 1С — компонент выгрузки по REST:

catalogSync.php 
<?php
// Получаем обновлённые позиции из 1С по REST
$response = file_get_contents('https://1c.pstm.ru/hs/export/catalog', [
    'http' => [
        'header' =>
            "Authorization: Basic " . base64_encode($login . ':' . $pass) . "
            Content-Type: application/json",
        'timeout' => 30,
    ],
]);

$items = json_decode($response, true);

foreach ($items as $item) {
    // Обновляем товар или создаём новый в MODX
    $res = $modx->runProcessor('resource/update', [
        'id'       => $map[$item['sku']] ?? 0,
        'pagetitle' => $item['name'],
        'price'    => (int)$item['price_opt'] ?? (int)$item['price'],
    ]);
}

$modx->log(xPDO::LOG_LEVEL_INFO, "Catalog synced: " . count($items));

Такой подход позволил держать цены актуальными во всём каталоге: инженер в 1С меняет цену один раз, и она автоматически появляется на сайте. Синхронизация запускается по расписанию, а при ошибке менеджер получает уведомление в Telegram.

4. Формы и работа с заявками

Любая форма на сайте — от «Заказать звонок» до «Рассчитать стоимость» — уходит сразу в три места: в CRM, на почту и в Telegram-бот менеджера. Порядок задач из чата автоматически закрывается после звонка клиенту, поэтому ни одна заявка не теряется.

5. Дизайн и фирменный стиль

Отталкивались от индустрии: строгие цвета, крупные модули, честные фотографии продукции. Отрисовали адаптивный дизайн, уделив особое внимание мобильной версии — больше половины заявок приходят именно со смартфонов.

Мобильная версия — 60% заявок с телефона

6. SEO и запуск

SEO закладывали на этапе структуры: семантическое ядро, ЧПУ-адреса, микроразметка Schema.org, мета-теги и адаптив. После запуска — выгрузка в поисковые системы и точечные доработки по результатам аудита. Через 6 месяцев портал вышел в топ-5 по коммерческим запросам отрасли.
